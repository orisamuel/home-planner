# home-planner

A small shopping list for furnishing a home, shared by two phones.

- Static site (HTML, CSS, vanilla JS), hosted on GitHub Pages.
- Data lives in a private Google Sheet behind a Google Apps Script web app. The script URL in `config.js` is public by design; every call except `ping` needs a shared house code, which is not in this repo.
- Photos are shrunk on the phone and stored in a private Google Drive folder.

This repository holds code only. No plans, addresses, budgets or personal data.
